# CDX — статический дизайн-прототип сайта

Дизайн-макет сайта таможенного брокера CDX (Customs · Delivery · Compliance).
HTML/CSS/JS без сборки — открывается напрямую в браузере.

**Live:** https://zif91.github.io/cdx/

## Структура

```
ROOT
├── index.html              Главная (продающий хиро + услуги + процесс + почему + отрасли + ФОС)
├── services.html           Услуги (хаб 8 направлений ВЭД)
│   └── service-hub.html    Сертификация и испытания (информационная — шаблон)
│       └── service.html    Нотификация ФСБ (конкретная услуга — шаблон)
│
├── reference.html          Справочник (хаб над разделами)
│   ├── tnved.html          ТН ВЭД (21 раздел + поиск)
│   ├── npa-index.html      Нормативные акты (листинг)
│   │   └── npa.html        ТР ТС 037/2016 (одиночный НПА — шаблон)
│   ├── glossary.html       Глоссарий (А–Я + латиница)
│   └── blog.html           Блог (статьи + новости)
│       ├── article.html    Экспертная статья — шаблон
│       └── news.html       Новость — шаблон
│
├── about.html              О компании
└── contacts.html           Контакты (форма + 6 отделов + карта)
```

## Дизайн-система

— `cdx.css` (3400+ строк) — единый источник стилей для всех страниц
— Темы: тёмная (по умолчанию) + светлая, переключатель в шапке, выбор сохраняется в localStorage
— Шрифты: Geologica (display) + Onest (body) + JetBrains Mono (data) + Inter (логотип, по брендбуку)
— Палитра: navy `#042C53` + accent `#4A6BFF` + brand X `#85B7EB` + warm `#F4B860`

## Особенности

— Продающий sales-hero на страницах услуг: заголовок с акцентами, буллеты выгод, цена, встроенная ФОС
— Блок «риски без документа» с цитированием КоАП РФ
— Квиз-калькулятор (4 шага) с lead magnet (скидка 10%)
— Формы соответствуют 152-ФЗ: обязательное согласие на ПД + опциональное на маркетинг (38-ФЗ)
— Адаптив: desktop / tablet / mobile

## Шаблоны для CMS

Канвас клиента определил 5 шаблонов «которые мы сами плодим»:
1. `service-hub.html` — информационная (сводная по разделу)
2. `service.html` — отдельная услуга
3. `article.html` — статья в блоге
4. `news.html` — новость
5. `npa.html` — нормативно-правовой акт

Плюс 3 фиксированные страницы: `index.html`, `about.html`, `contacts.html`.
